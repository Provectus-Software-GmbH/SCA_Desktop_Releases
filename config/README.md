# Secure Contacts Configuration

This folder contains the Microsoft Intune and MDM configuration templates for Secure Contacts Desktop.

## Choose a platform

| Platform | Configuration assets and guide |
|---|---|
| Windows | [Windows configuration guide](Windows/README.Intune-Config-Win.md) - ADMX/ADML templates and Policy CSP OMA-URI options |
| macOS | [macOS configuration guide](MacOS/README.Intune-Config-MacOS.md) - managed-preferences plist templates |

Each platform folder contains its own templates, examples, import or deployment references, and supporting documentation.

For application downloads, validation, publishing, and removal, start from the [repository README](../README.md) and use the deployment or uninstall guides there.
